# 🗑️ 내가 쓴 포스트 삭제 기능 구현 계획서

회원님께서 원하시는 "직접 작성한 포스트 삭제 기능"을 DB와 완벽하게 연동하여 구현하겠습니다. 

## 1. 프론트엔드 (UI 및 상태 동기화)
- **삭제 버튼 추가:** 포스트를 클릭했을 때 나오는 '상세 보기 모달창(PostDetailModal)' 내부에 **휴지통(🗑️) 삭제 버튼**을 추가합니다. 
- **소유권 확인:** 이 버튼은 오직 `post.isOwn === true` (즉, 회원님이 직접 쓴 글)일 때만 화면에 나타납니다. 다른 사람의 글에는 삭제 버튼이 보이지 않습니다.
- **실시간 반영:** 삭제 완료 시 새로고침 없이 화면에서 해당 포스트잇이 즉시 스르륵 사라지도록 상태 동기화 로직을 추가합니다.

## 2. 백엔드 (DB 연동 및 점수 차감)
- **API 업데이트:** 삭제 요청을 처리할 수 있도록 기존 `/api/posts/[id]` 백엔드 라우터를 고도화합니다.
- **점수 정산 (어뷰징 방지):** 글을 삭제하면 해당 글을 쓸 때 받았던 **선행 지수(포인트)를 다시 차감**하여 DB 정합성을 100% 유지합니다. (이벤트로 받은 추가 점수까지 완벽히 계산하여 돌려놓습니다)
- **고아 데이터 정리:** 해당 글에 다른 사람들이 눌러준 '나도요(좋아요)' 데이터들도 함께 깔끔하게 삭제(Cascade)하여 DB에 불필요한 찌꺼기 데이터가 남지 않게 합니다.

> [!TIP]
> DB와 점수, 화면까지 완벽하게 동기화되는 진짜 삭제 기능을 만들어드리겠습니다. **승인(Proceed)** 버튼을 눌러주시면 즉시 코드 작업을 시작하겠습니다! 🛠️
